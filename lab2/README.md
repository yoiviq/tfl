### 4. Расширенная регулярка

^(ab?c|ba?c)*(?=.....$)ba.(a|b)(b|c)

#### Пояснение эквивалентности регулярных выражений:

1. Итерационный блок переписан для читаемости, по факту есть два варианта с вхождением b/a в середине или без

2. Использован lookahead для решения проблемы недетерминизма между bac, принадлежащем первому блоку, и bac, являющимся началом второго блока фиксированной длины

3. (a|b|c) в алфавите {a, b, c} заменен на .
